# Contributing to elyan-macos-security

## Development Setup

```bash
git clone https://github.com/MingYu5/elyan-macos-security.git
cd elyan-macos-security
```

## Contributing

1. Fork the repo
2. Create a feature branch
3. Open PR against `Scottcjn/elyan-macos-security:main`

Questions? Open an issue!
